# Contributing

Thanks for helping improve the AI Engineer Dictionary.

1. Search existing entries before proposing a new term.
2. Open an issue for a new term or a substantial structural change.
3. Fork the repository and create a focused branch.
4. Use `dictionary/TEMPLATE.qmd` for new entries.
5. Cite reliable sources and write explanations in your own words.
6. Add a notebook only when code or an experiment improves understanding.
7. Run `python scripts/validate_entries.py`.
8. Open a pull request with a concise summary and sources.

Keep pull requests focused. One term or a small, related group of terms per
pull request is easier to review.

Never commit API keys, passwords, private datasets, or other secrets.
