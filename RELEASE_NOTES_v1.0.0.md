# AI Engineer Dictionary v1.0.0

The first prepared release of the AI Engineer Dictionary: an open-source,
community-maintained A–Z reference for AI engineering.`

## Highlights

- 347 unique terms spanning AI fundamentals, machine learning, deep learning,
  LLM engineering, agents, retrieval, MLOps, infrastructure, robotics, and
  software engineering.
- Quarto website with search, letter indexes, navigation, mathematical
  notation, and selected explanatory diagrams.
- Practical notebooks for selected concepts.
- Contribution workflows for bug reports, new terminology proposals,
  definition improvements, and pull requests.
- A local entry metadata and duplicate-term validator.
- Vercel deployment configuration and instructions for automatic production
  and pull-request preview deployments after the repository is connected.
