# AI Engineer Dictionary v1.0.0

The first release of the AI Engineer Dictionary: an open-source,
community-maintained A–Z reference to modern AI engineering.

**Live website:** [ai-engineer-dictionary.vercel.app](https://ai-engineer-dictionary.vercel.app/)

## Highlights

- 347 dictionary terms spanning AI fundamentals, machine learning, deep
  learning, LLM engineering, agents, retrieval, MLOps, infrastructure,
  robotics, and software engineering.
- A searchable Quarto website with alphabetic indexes, related-term
  navigation, mathematical notation, and explanatory diagrams.
- Practical Jupyter notebooks for selected concepts.
- GitHub contribution forms for bug reports, terminology proposals, and
  definition improvements, plus a pull request checklist.
- A local validator for entry metadata and duplicate terms.
- Vercel deployment configuration and setup guidance for production and
  pull-request preview deployments.
